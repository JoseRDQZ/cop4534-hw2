COP 4534 – Homework 2
Author: Jose Rodriguez

This submission contains the solutions for Homework 2 of COP 4534.
The assignment consists of multiple independent problems, each implemented
as a separate Python program.

Each program is self-contained and prints its output directly to the console.

--------------------------------------------------------------------------

Problem 1 – Music Festival Scheduler
File: musicFestScheduler.py

This program solves a scheduling problem for a music festival while respecting
time and conflict constraints between performances.

The program accepts manual input from the user and outputs a valid schedule
based on the provided constraints.

--------------------------------------------------------------------------

Problem 2 – Freight Network Planner
File: freightNetworkPlanner.py

This program computes efficient freight transportation routes with the goal
of minimizing overall cost.

The program can be executed using either predefined demo data or custom
user-provided input.

--------------------------------------------------------------------------

Problem 3 – Emergency Route Finder
File: emergencyRouteFinder.py

This program determines optimal rescue routes in emergency scenarios using
graph traversal techniques.

The program supports both predefined datasets and custom user input.

--------------------------------------------------------------------------

Problem 4 – Conference Scheduler
File: conferenceScheduler.py

This program schedules conference sessions while avoiding conflicts between
rooms and time slots.

The program supports demo execution as well as user-defined scheduling
constraints.

--------------------------------------------------------------------------

How to Run

1. Open the HW2 directory in a Python-compatible editor or IDE.
2. Select the Python file corresponding to the problem you want to run.
3. Execute the program using Python 3.
4. Follow any on-screen prompts if applicable.

--------------------------------------------------------------------------

Requirements

- Python 3.x
- No external libraries required
- Uses only standard Python modules
